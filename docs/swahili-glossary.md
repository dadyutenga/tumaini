# Swahili glossary

Simple, everyday Tanzanian Swahili, as used in a shop. Use these words consistently in
`frontend/src/features/i18n/locales/sw`. Add a term here when you introduce one.

Kept in English: M-Pesa, TIN, IMEI, PDF, WhatsApp, SMS, SKU, POS, barcode, brand names.
